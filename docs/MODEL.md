# PMSM Drive Lab — математическая модель

Версия 0.1. Все расчёты в SI; в интерфейсе время отображается в ms,
момент в mN·m, индуктивности в µH, поток в mWb. Скорость на графиках rpm.
Эта модель пригодна для воспроизводимых численных экспериментов.
Её точность для реального двигателя требует идентификации и валидации.

1. Исходные данные и происхождение параметров

Источник: предоставленный пользователем Cataloge-Page-EN-193.pdf,
maxon ECX SPEED 4 M, Ø4 mm, каталог March 2025, стр. 193.
В оригинале двигатель обозначен BLDC. Форма фазной ЭДС, соединение обмоток,
Ld/Lq и нормировка паспортного тока для синусоидального FOC не заданы.
Поэтому каталог НЕ является достаточным источником идентифицированной PMSM.
Сохранён оригинальный PDF; авторские права на него принадлежат maxon.

Принят эквивалент симметричной звезды с изолированной нейтралью:
  R_phase = R_terminal / 2
  Ld = Lq = L_terminal / 2
Взаимная индуктивность включена в эффективную фазную индуктивность.
Это модельный эквивалент, а не утверждение о внутренней схеме двигателя.
Для другого соединения/идентификации задайте R, Ld, Lq непосредственно.

Инерция: 1 g·cm² = 10⁻⁷ kg·m²; J = 1.11 × 10⁻¹⁰ kg·m².
Инерция присоединённой нагрузки добавляется к J вручную.

Условная калибровка констант для эквивалента шестиступенчатой коммутации:
предполагаем, что каталоговый ток Icat — ток двух проводящих фаз.
Приравниваем медные потери R_terminal Icat² = (3/2) R_phase iq²:
  iq = (2/√3) Icat
Приравниваем момент Kt_cat Icat = (3/2) p ψm iq:
  ψm = Kt_cat / (√3 p).
Для 3 V: ψm ≈ 0.440518 mWb; для 6 V: ≈ 0.883346 mWb.
Это явно принятое допущение о нормировке; оно НЕ подтверждено данным PDF.
Для научной идентификации замените ψm по измеренной фазной ЭДС:
  ψm = E_phase_peak / ωe = √2 E_line_RMS / (√3 ωe).
При другой нормировке Kt пересчёт должен быть изменён.
Константа скорости даёт Ke_eff = 60/(2π Kv), близкое к Kt_cat в SI;
это контроль согласованности округлённых данных, не отдельная идентификация.

Вязкое трение приближённо оценивается по холостому ходу:
  B ≈ Kt_cat I0 / ω0.
Все потери холостого хода условно представлены вязким трением.
В реальности они содержат потери в стали, подшипниках и аэродинамике.
Этот B нельзя считать измеренным коэффициентом вязкого трения.

Предел задания тока по умолчанию: 2 I_stall / √3 (фазная амплитуда).
Справочный длительный фазный RMS: √(2/3) I_nominal.
Ограничивается вектор ЗАДАНИЯ тока, а не мгновенный физический ток.
Коммутационные пульсации и переходные процессы могут превышать этот предел.
Температура не рассчитывается; предупреждение RMS не заменяет тепловую модель.
Паспортные тепловые величины сохранены в CATALOG_COMMON для расширения модели.

2. Координатные преобразования [1, 2]

Амплитудно-инвариантный Кларк (для трёхпроводной системы xₐ+xᵦ+x꜀=0):
  xα = (2xₐ − xᵦ − x꜀) / 3
  xβ = (xᵦ − x꜀) / √3
Обратный Кларк:
  xₐ = xα
  xᵦ = −xα/2 + √3 xβ/2
  x꜀ = −xα/2 − √3 xβ/2

Парк, d-ось направлена по потоку постоянного магнита:
  xd =  cos(θe) xα + sin(θe) xβ
  xq = −sin(θe) xα + cos(θe) xβ
Обратный Парк:
  xα = cos(θe) xd − sin(θe) xq
  xβ = sin(θe) xd + cos(θe) xq

Преобразования одинаковы для токов, напряжений и ЭДС.
  ωe = p ωm;  dθe/dt = ωe;  n[rpm] = 30 ωm / π.
  P = vₐiₐ + vᵦiᵦ + v꜀i꜀ = (3/2)(vd id + vq iq).
Нулевой последовательности в фазных токах и напряжениях на обмотках нет.
Общий модульирующий сигнал инвертора не прикладывается к плавающей нейтрали.

3. Электрическая и механическая модель [1, 2]

Потокосцепления:
  λd = Ld id + ψm;  λq = Lq iq.
  did/dt = (vd − R id + ωe Lq iq) / Ld
  diq/dt = (vq − R iq − ωe (Ld id + ψm)) / Lq

Электромагнитный момент, включая реактивную составляющую IPMSM:
  Te = (3/2) p [ψm iq + (Ld − Lq) id iq].
По умолчанию Ld=Lq (SPMSM-аппроксимация); Ld и Lq редактируются отдельно.

Динамика ротора:
  J dωm/dt = Te − TL − B ωm.
TL — подписанный внешний противодействующий момент, не его модуль.
Положительный TL вычитается при любом знаке скорости; при реверсе
резистивную нагрузку нужно задавать с соответствующим знаком.
Если требуется закон трения/нагрузки от скорости, его следует добавить отдельно.
Te − Bω — доступный момент после модельного трения; он равен TL только
при нулевом ускорении. В интерфейсе показаны все эти величины раздельно.

Обратная ЭДС ПОСТОЯННЫХ МАГНИТОВ (не включает L di/dt):
  ed = 0; eq = ωe ψm
  eα = −ωe ψm sin(θe); eβ = ωe ψm cos(θe)
  eₐ, eᵦ, e꜀ = inverse_Clarke(eα, eβ).

Мощности и запасённая энергия:
  Pcu = R (iₐ² + iᵦ² + i꜀²)
  Pmech = Te ωm; Pload = TL ωm; Pfriction = B ωm²
  W = (3/4)(Ld id² + Lq iq²) + (1/2) J ωm²
  dW/dt = Pelec − Pcu − Pload − Pfriction.
Для идеального инвертора Pdc = Vdc (Sa iₐ + Sb iᵦ + Sc i꜀) = Pelec.
Модель жёсткой DC-шины допускает рекуперацию; батарея/выпрямитель не моделируются.
Дискретные экспорты мощности не содержат всех несеточных фронтов: для точного
интеграла мощности нужна сходимость по шагу или интеграция на внутренних фронтах.
Тест энергетического баланса проверяет тождество ОДУ, не точность такого интеграла.

4. Шестиключевой инвертор и ШИМ [3]

Команда vd*, vq* ограничивается окружностью Vdc/√3 (линейная область SVPWM).
Обратные Парк и Кларк выполняются по θe на начале периода управления.
Три задания напряжений удерживаются на весь период ШИМ.
Минимаксная инжекция нулевой последовательности:
  v0 = −(max(vₐ*,vᵦ*,v꜀*) + min(vₐ*,vᵦ*,v꜀*)) / 2
  dₖ = 1/2 + (vₖ* + v0)/Vdc.
Двухскатная несущая c(φ)=1−|2φ−1|, φ∈[0,1].
  Sₖ_upper = 1 если dₖ > c(φ), иначе 0
  Sₖ_lower = 1 − Sₖ_upper
  vₖn = Vdc [Sₖ_upper − (Sa+Sb+Sc)/3].
Линейные напряжения: vab=va−vb, vbc=vb−vc, vca=vc−va.
Ключи идеальны, dead-time, падения напряжения, паразитные параметры,
потери коммутации и диоды как отдельные элементы не моделируются.
Обратный ток допускается через идеальный управляемый полюс.

5. FOC [1, 2, 4]

Период контроллера = период ШИМ. Датчик угла идеальный.
Контроллер получает средние id, iq, ω предыдущего периода ШИМ
(задержка измерения явно присутствует). Это модель идеального усредняющего АЦП.
Начальные измерения равны начальному состоянию.
По умолчанию id*=0. MTPA и автоматическое ослабление поля не реализованы.

Контур скорости: iq_raw* = Kpω (ω*−ω) + zω,
  Kpω = 2 ζ ωn J / Kτ; Kiω = ωn² J / Kτ
  Kτ = (3/2)p[ψm+(Ld−Lq)id*], ωn=2π f_speed.
Это приближение второго порядка при быстром контуре тока и малом B.
  |iq*| ≤ √(I_limit² − id*²).

Контуры токов:
  vd_raw* = Kpd (id*−id) + zd − ωe Lq iq
  vq_raw* = Kpq (iq*−iq) + zq + ωe (Ld id + ψm)
  Kpd = Ld ωci; Kpq = Lq ωci; Kid=Kiq=R ωci; ωci=2π f_current.
Развязка обратной ЭДС и перекрёстных связей может быть отключена.
Векторные команды ограничиваются окружностью напряжения.

Anti-windup методом обратного расчёта:
  z[k+1] = z[k] + Ts [Ki error + Kaw (u_limited − u_raw)].
Kaw тока = ωci; Kaw скорости = ωn.
При насыщении напряжения и совпадении знаков ошибки скорости и iq*
добавление Kiω error в интегратор скорости замораживается; отслеживание
ограниченного iq* продолжается. Это реализованный вариант anti-windup,
а не доказательство глобальной устойчивости для произвольных параметров.
Граничные режимы следует исследовать отдельно.

6. Численный метод и временные сигналы

Фиксированная внешняя сетка dt = 1/(fPWM × Nsubsteps), RK4.
Каждый шаг дополнительно разбивается на ТОЧНЫХ фронтах PWM по всем фазам.
Поэтому скважность не округляется к внешней сетке. На каждом подынтервале
фазное напряжение постоянно, а преобразование Парк внутри RK4 учитывает θe.
На равномерной сетке записываются мгновенные состояния и состояния ключей.
Экспорт ключей — дискретные отсчёты, а не полный список несеточных событий.
Внешняя нагрузка ступенчата или линейна по заданным узлам.
Ступень нагрузки применяется на ближайшей следующей точке сетки (задержка <dt).
Скоростная команда применяется на ближайшем периоде управления (<1/fPWM).
Вводимые времена и исходные задания также сохраняются в JSON.
Длительность округляется вверх до полного периода PWM и отражается в метриках.

Численные ограничения: dt≤min(Ld,Lq)/(10R), f_current≤fPWM/10,
f_speed≤f_current/5, максимум 1 200 000 шагов на один опыт.
Эти проверки помогают задать разумное разрешение, но не гарантируют устойчивость
любых пользовательских параметров. Сходимость подтверждается уменьшением dt.
По умолчанию: 100 kHz, 40 подшагов, dt=0.25 µs, 120 ms.
Начальные токи нулевые, скорость и электрический угол редактируются.

Обзорные графики сохраняют экстремумы каждого канала внутри временных блоков.
Это сокращённые данные: они непригодны для FFT или измерения фронтов.
Откройте осциллоскоп, выберите 100 µs или приблизьте интервал; подпись указывает,
возвращена ли полная сетка. CSV/NPZ всегда содержат все исходные отсчёты.
Метрики тока: RMS по трём фазам за весь опыт и последние 5 ms.
Скорость/момент в карточках усредняются за последние 5 ms (либо весь короткий опыт).

7. Подключение другого управления

pmsm_lab.controllers.Controller — протокол reset(motor, sample_time),
step(Observation) → VoltageCommand(vd,vq,id_reference,iq_reference,saturated).
simulate(config, controller=MyController()) использует тот же физический объект,
инвертор и период дискретизации. Пример адаптера RL — examples/rl_adapter.py.
Двигатель не требует знания типа контроллера. Последнее ограничение напряжения
и генерация комплементарных ключей выполняются в симуляторе для любой политики.
Аппаратная токовая защита, Gymnasium Env, reward, обучение RL и экспорт политики
пока не реализованы. Стандартный пользовательский интерфейс запускает FOC.
