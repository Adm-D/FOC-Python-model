# Отчёт о проверках

Проверено 7 ноября 2026 г. в текущей облачной среде, Python 3.12.14.
Точные версии зависимостей — `requirements.lock`. Проверки ниже относятся
к вычислительной реализации; измерений реального двигателя в этой работе нет.

## Автоматические проверки

`python -m pytest -q`: **25 passed**.

- Прямые и обратные Кларк/Парк, равенство мощностей abc и dq.
- Пересчёт параметров каталога и равенство принятых медных потерь.
- RL-цепь при неподвижном роторе: сравнение с аналитической экспонентой.
- Дифференциальный баланс энергии при Ld ≠ Lq.
- Равенство мощности PM-ЭДС и мощности соответствующей составляющей момента.
- Точное среднее фазное напряжение PWM за период при разных углах ротора.
- FOC с набросом нагрузки, обе обмотки, реверс, выход из насыщения.
- Комплементарность всех ключей, законы Кирхгофа, Pdc = Pelec.
- Ограничение напряжения для внешнего контроллера, сохранение пиков обзора.
- Ступенчатые/линейные сценарии, отклонение некорректных параметров.
- HTTP API, JSON, CSV, NPZ, оригинальный PDF и документация.

Предупреждение тестового инструментария: установленный Starlette сообщает
о будущем переходе TestClient с httpx на httpx2. Ошибок выполнения нет;
предупреждение не подавляется и не относится к физической модели.

## Стандартный опыт

Обмотка 3 V, PWM 100 kHz, 40 подшагов, dt = 0.25 µs, длительность 120 ms.
Задания скорости: 12000 → 22000 → 16000 rpm (0, 40, 80 ms).
Момент нагрузки: 0 → 0.08 → 0.14 mN·m (0, 60, 100 ms).

| Показатель | Результат |
|---|---:|
| Число временных точек | 480001 |
| Средняя скорость, последние 5 ms | 15999.9534 rpm |
| Ошибка относительно последнего задания | −0.0466 rpm |
| Мгновенная конечная скорость | 16001.0527 rpm |
| Средний Te, последние 5 ms | 0.149960 mN·m |
| Фазный RMS за весь опыт | 0.090266 A |
| Фазный RMS за последние 5 ms | 0.161408 A |
| Максимум модуля фазного тока | 0.373186 A |

Средний электромагнитный момент выше внешней нагрузки из-за модельного
вязкого трения. Расчёт после компиляции занимал около 0.7–1 s в этой среде;
первый запуск компилирует ядро, поэтому его длительность больше.

## Локальный запуск из архива

После добавления `main.py` архив распакован в отдельную папку с пробелами в пути.
Запуск выполнен системным Python 3.12 из другого рабочего каталога. Проверены:

- Создание нового `.venv` и установка зависимостей из `requirements.lock`.
- Получение интерфейса и выполнение локального опыта на 16001 временной точке.
- Остановка из терминала по SIGINT (Ctrl+C) и повторное освобождение порта.
- Повторный запуск с готовыми зависимостями без вызова pip.
- Вызов открытия браузера только после готовности локального HTTP-сервера
  (сам вызов браузера перехвачен тестом; готовность проверена HTTP-запросом).
- Справка `--help` и отклонение некорректного порта до установки зависимостей.

Проверка проведена в Linux; отдельный запуск в Windows/macOS не выполнялся.
